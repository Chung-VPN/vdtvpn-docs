VDTVPN documentation and support

VDTVPN is a client application for importing and managing user-provided connection profiles. The app does not provide built-in servers or preloaded connection profiles.

What VDTVPN does

Import profiles

Users can import connection profiles using a subscription URL or QR code.

Manage configurations

The app helps users organize and select their own connection configurations.

User controlled

Connections are started and stopped by the user through Android VPNService.

Important notes

VDTVPN does not sell, provide, or operate VPN servers inside the app. Users are responsible for the configuration sources and third-party subscriptions they choose to use.
